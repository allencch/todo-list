# Todo List

This is a simple Todo List web application.

## Requirement

`asdf` (or `mise`). Refer to `.tool-versions` involved.

## Stack

Backend
- NodeJS
- Fastify

Database
- PostgreSQL
- Drizzle

Frontend
- Vue
- Tailwind
- Vite


## Commands cheatsheet

Run test environment migration

```bash
# in api
pnpm drizzle-kit migrate --config=drizzle.test.config.ts
```
